# روان‌سنج صنعتی (Ravansanj Sanati) — نسخه ۳.۰.۰

سامانه جامع و چندرایانه‌ای **روان‌سنجی استاندارد صنعتی، پایش سلامت و ایمنی کارکنان (HSE / طب کار) و جایابی هوشمند شغلی**؛ قابل استفاده به‌صورت **تحت وب** و **نرم‌افزار دسکتاپ ویندوز (Tauri v2)**.

این سامانه علاوه بر پشتیبانی از همگام‌سازی ابری بین چند ایستگاه (از طریق Firebase Firestore)، برای محیط‌های صنعتی فاقد دسترسی به سرویس‌های گوگل نیز یک حالت **محلی / آفلاین کامل** با ورود از طریق کد ملی، کد پرسنلی یا نام کاربری و رمز عبور ارائه می‌دهد.

---

## کاربردهای اصلی سامانه

1. **تعیین مستقیم تناسب شخصیت با محیط کار (پشت‌میزی در برابر میدانی، فنی و آزمایشگاهی):**
   - با ترکیب آزمون رغبت‌سنج شغلی هالند (`O*NET Mini-IP / RIASEC`) و پنج‌عامل بزرگ (`Mini-IPIP`)، میزان تناسب فرد به‌صورت درصدی و تحلیلی برای ۵ تیپ محیط کار محاسبه می‌شود:
     - کار **پشت‌میزی، اداری، مالی و برنامه‌ریزی**
     - کار **میدانی، خطوط تولید و عملیات انبار**
     - کار **فنی-کارگاهی، مهندسی و نگهداری و تعمیرات**
     - کار **آزمایشگاهی، کنترل کیفیت و تحقیق و توسعه**
     - کار **مدیریتی، سرپرستی، فروش و بازرگانی**
   - رتبه‌بندی خودکار **۳۵ واحد کاری کارخانه** و نمایش ۵ واحد برتر پیشنهادی به همراه درصد انطباق با واحد فعلی فرد.

2. **ارزیابی پیش از استخدام و نقل‌وانتقال درون‌سازمانی:**
   - غربالگری داوطلبان جدید و شناسایی هم‌سویی ویژگی‌های شخصیتی، درست‌کاری و توان شناختی با شغل مورد تقاضا.

3. **پایش دوره‌ای ایمنی، خستگی و سلامت روان‌شناختی شاغلین (HSE و طب کار):**
   - شناسایی ریسک خطاهای ایمنی، خواب‌آلودگی خطرناک در شیفت‌ها و اپراتوری تجهیزات سنگین (لیفتراک، نورد، برق)، فرسودگی شغلی و فشار روانی نیازمند پیگیری تخصصی.

4. **مدیریت متمرکز پرسنل ۳۵ واحد کاری و گزارش‌گیری چاپی / اکسل:**
   - بارگذاری دسته‌جمعی ۳۱۸ پرسنل کارخانه تنها با یک کلیک، فیلتر بر اساس ۷ گروه شغلی و ۳۵ واحد کاری، خروجی اکسل (`CSV` با پشتیبانی کامل فارسی `UTF-8 BOM`)، پشتیبان‌گیری کامل (`JSON`) و چاپ گزارش استاندارد `A4` / `PDF`.

## محتویات علمی و آزمون‌های استاندارد سامانه

تمامی ابزارهای این برنامه بر پایه آزمون‌های معتبر و داوری‌شده‌ی دانشگاهی پیاده‌سازی شده‌اند:

### الف) پرسشنامه‌های استاندارد

| نام آزمون | مرجع علمی | تعداد گویه | ابعاد سنجش و کاربرد صنعتی |
| :--- | :--- | :---: | :--- |
| **رغبت‌سنج شغلی هالند (O\*NET Mini-IP / RIASEC)** | Holland (1997); Rounds et al. (2010) | ۳۰ | سنجش تیپ‌های ۶گانه `R-I-A-S-E-C` و محاسبه مستقیم تناسب پشت‌میزی، میدانی، فنی و ۳۵ واحد شرکت |
| **شخصیت‌سنج پنج‌عامل بزرگ (Mini-IPIP)** | Donnellan et al. (2006); Barrick & Mount (1991) | ۲۰ | برون‌گرایی، توافق‌پذیری، وظیفه‌شناسی، ناپایداری هیجانی و گشودگی به تجربه |
| **سلامت روان (DASS-21)** | Lovibond & Lovibond (1995)؛ هنجار ایرانی صاحبی و همکاران | ۲۱ | غربالگری افسردگی، اضطراب و استرس شغلی در پایش کارکنان |
| **رفتار ایمنی و گرایش به ریسک** | Griffin & Neal (2000); Meertens & Lion (2008) | ۱۶ | تبعیت از مقررات ایمنی، مشارکت ایمنی و ریسک‌پذیری در کارهای پرخطر |
| **صداقت-تواضع و روایی پاسخ** | HEXACO-H (Ashton & Lee, 2009) + Marlowe-Crowne Short Form (Reynolds, 1982) | ۱۴ | سنجش درست‌کاری، انصاف و پرهیز از طمع به همراه شاخص مطلوبیت اجتماعی (تشخیص آرمانی‌نمایی) |
| **فرسودگی شغلی اولدنبورگ (OLBI)** | Demerouti et al. (2003); Peterson et al. (2008) | ۱۶ | خستگی جسمانی/هیجانی و گسستگی از کار (با گویه‌های متعادل مثبت و منفی) |
| **مقیاس خواب‌آلودگی اپورث (ESS)** | Johns (1991) | ۸ | احتمال چرت‌زدن و خواب‌آلودگی روزانه در موقعیت‌های کاری و رانندگی (نمره ۰ تا ۲۴) |

### ب) آزمون‌های عملکردی و شناختی (کامپیوتری)

| نام آزمون | مرجع علمی | شاخص‌های اندازه‌گیری |
| :--- | :--- | :--- |
| **زمان واکنش و هوشیاری (PVT)** | Dinges & Powell (1985) | میانگین زمان واکنش (ms)، نوسان توجه (Lapses) و خطای پیش‌دستی (تکانشگری) |
| **آزمون تداخل رنگ و واژه استروپ (Stroop)** | Stroop (1935) | اثر تداخل شناختی، توجه انتخابی و دقت در محرک‌های ناهمخوان |
| **فراخنای ارقام مستقیم و معکوس (Digit Span)** | زیرآزمون استاندارد وکسلر (WAIS) | حافظه کوتاه‌مدت، حافظه کاری و دقت ثبت کدها و اعداد |
| **آزمون ردیابی (Trail Making Test A & B)** | Reitan (1958) | سرعت پردازش دیداری-حرکتی (بخش الف) و انعطاف‌پذیری شناختی/تغییر تکلیف (بخش ب) |

## دسته‌بندی ۷گانه و ۳۵ واحد کاری کارخانه

فهرست واحدهای کاری سامانه مطابق ساختار سازمانی استخراج‌شده از لیست پرسنل کارخانه به تفکیک ماهیت محیط کار دسته‌بندی شده است:

1. **تولید و بهره‌برداری (`میدانی و خط تولید`):** تولید گالوانیزه، تولید گالوانیزه و رنگی، تولید نورد سرد، تولید نورد سرد و اسید شویی، تولید اسید شویی، برش، بسته بندی، برش و بسته بندی، نقاشی، بهره برداری
2. **فنی، مهندسی و نت (`فنی، کارگاهی و میدانی تخصصی`):** فنی و مهندسی، تاسیسات، برق، الکترونیک، هیدرولیک، تعمیرات، نگهداری و تعمیرات، ماشین سازی، CNC سنگ، جوشکاری
3. **کنترل کیفیت و آزمایشگاه (`آزمایشگاهی و تحلیلی`):** کنترل کیفیت، تضمین کیفیت، آزمایشگاه، کالیبراسیون، بازرسی، تحقیق و توسعه
4. **انبارها و لجستیک (`میدانی و کنترل موجودی`):** انبار مواد اولیه و محصول، انبار قطعات، لیفتراک
5. **اداری، مالی و برنامه‌ریزی (`پشت‌میزی، ستادی و مالی`):** اداری، مالی و صندوق، آمار و برنامه ریزی، انفورماتیک، دفتر مدیریت، آموزش
6. **مدیریت، فروش و بازرگانی (`مدیریتی، سرپرستی و بازرگانی`):** مدیریت کارخانه، مدیر فنی، مدیران اجرایی و مشاوره ای، مدیرعامل، فروش، بازرگانی
7. **ایمنی، انتظامات و خدمات (`میدانی-نظارتی و پشتیبانی`):** ایمنی و بهداشت، انتظامات، خدمات، آشپزخانه

## سطوح دسترسی و روش‌های احراز هویت

سامانه سه مسیر ورود متناسب با نیاز محیط صنعتی دارد:

1. **ورود پرسنل (بدون نیاز به حساب گوگل):**
   - با وارد کردن **کد ملی (۱۰ رقم)**، **کد پرسنلی** یا **شماره موبایل**، مشخصات و واحد کاری فرد به‌طور خودکار از فهرست پایه بارگذاری می‌شود.
   - این نقش صرفاً به بخش «تکمیل آزمون»، «نتیجه و پیشنهاد شغلی خود فرد» و «راهنما» دسترسی دارد و به نتایج سایر همکاران یا حذف داده‌ها دسترسی نخواهد داشت.

2. **ورود مدیران و ارزیابان / HSE (نام کاربری و رمز عبور):**
   - دسترسی کامل به داشبورد تحلیلی، مدیریت پرسنل، اجرای آزمون، مشاهده و چاپ گزارش‌ها، و پشتیبان‌گیری.
   - در **اولین ورود**، سامانه کاربر مدیر یا ارزیاب را ملزم به تغییر رمز عبور می‌کند.
   - حساب‌های پیش‌فرض اولیه:
     - مدیر سیستم: نام کاربری `admin` / رمز اولیه `admin123`
     - ارزیاب طب کار: نام کاربری `evaluator` / رمز اولیه `eval123`
   - *توصیه امنیتی: پس از اولین ورود در محیط کارخانه حتماً رمز عبور پیش‌فرض را تغییر دهید.*

3. **ورود با حساب گوگل (حالت ابری چندرایانه‌ای):**
   - در صورت دسترسی به اینترنت و حساب گوگل، داده‌ها به‌صورت لحظه‌ای از طریق **Cloud Firestore** بین چندین رایانه (اتاق تست، واحد HSE، پزشک طب کار و منابع انسانی) همگام می‌شوند.
   - در صورت ورود با کد ملی یا نام کاربری محلی، ذخیره‌سازی به‌طور خودکار روی پایگاه داده محلی مرورگر/برنامه دسکتاپ انجام می‌شود تا هیچ خطای دسترسی به سرویس‌های ابری رخ ندهد.

## راه‌اندازی محلی و بیلد

### پیش‌نیازها
- Node.js نسخه ۲۰ یا ۲۲ به بالا
- برای خروجی دسکتاپ ویندوز: Rust Toolchain (مورد نیاز Tauri v2)

### دستورات توسعه و بررسی کیفیت

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه تحت وب روی پورت 3000
npm run dev

# بررسی خطاهای TypeScript
npm run lint

# ساخت نسخه نهایی تحت وب (dist/)
npm run build
```

### ساخت اینستالر دسکتاپ ویندوز (به‌صورت محلی)

```bash
npx @tauri-apps/cli@2 build
```

## اتوماسیون CI/CD گیتهاب

با هر `push` روی شاخه‌ی اصلی (`main` یا `master`)، ورک‌فلو `.github/workflows/tauri-release.yml` به‌صورت خودکار مراحل زیر را اجرا می‌کند:

1. **بررسی کیفیت (`ci`):** اجرای `npm run lint` و `npm run build` برای اطمینان از سلامت کد.
2. **انتشار قوانین Firestore (`deploy-firebase`):** در صورت تنظیم سکرت `FIREBASE_SERVICE_ACCOUNT` در گیتهاب، فایل `firestore.rules` به‌طور خودکار دیپلوی می‌شود.
3. **نسخه‌گذاری خودکار (`version`):** اسکریپت `scripts/auto-version.mjs` بر اساس پیام کامیت‌ها و میزان تغییرات، نسخه جدید را در `package.json`، `src-tauri/tauri.conf.json` و `src-tauri/Cargo.toml` اعمال، تگ و Release ایجاد می‌کند.
4. **ساخت نصاب ویندوز (`build-tauri`):** کامپایل نسخه ویندوز با **Tauri v2** و پیوست کردن فایل‌های نصب (`.exe` / `.msi`) به Release و بخش Artifacts.
